Pairing

Pair this phone with your hub

You scanned the code your Switchboard hub showed. To finish:

  1. Install Tailscale and the Switchboard app on this phone, and sign in to Tailscale.
  2. Scan the code again with the phone's camera. The app opens with your hub and setup code filled in; add your name and create your passkey.

The setup code stays in your browser: it's in the part of the link that is never sent to this website. It works once, for 24 hours. A new one: switchboard-hub setup-code on the hub computer.
